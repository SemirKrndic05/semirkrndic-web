# Semir Krndić — portfolio

Ovo je statična verzija stranice spremna za GitHub Pages. Ne treba instalirati programe niti pokretati build.

## Postavljanje na GitHub

1. Na GitHubu napravi novi javni repozitorij.
2. U repozitorij učitaj fajlove index.html, style.css i script.js.
3. Otvori **Settings → Pages**.
4. Pod **Build and deployment** izaberi **Deploy from a branch**.
5. Izaberi granu **main**, folder **/(root)** i klikni **Save**.
6. GitHub će prikazati adresu stranice nakon objave.

## Vlastita domena

Kada domena bude kupljena, u **Settings → Pages → Custom domain** unesi svoju domenu. GitHub će prikazati DNS zapise koje treba dodati kod firme kod koje je domena kupljena.

Nakon što DNS proradi, uključi **Enforce HTTPS**.
